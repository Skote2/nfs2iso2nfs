# nfs2iso2nfs
convert nfs files to iso and back

The help menu provides instructions and can be printed with the -help argument.

# build

## Linux

1. install dotnet core v6.0
2. execute `$ dotnet build` in project directory
3. binary should be built into bin/Debug/net6.0/nfs2iso2nfs

## Windows

1. open project in Visual Studio with a .netv6.0 C# toolchain installed
2. click build

alternatively the linux instructions should work as well
